# Сервис Заявок - Клиентская часть

## Описание проекта

Клиентская часть приложения **Сервис Заявок** представляет собой современное веб-приложение, разработанное с использованием **React** и **Vite** для управления заявками. Приложение предоставляет удобный интерфейс для создания, просмотра, редактирования и обсуждения заявок, а также управления профилем пользователя и просмотра статистики. Оно интегрируется с серверной частью через REST API и WebSocket для обмена сообщениями в реальном времени.

Основные функции:

- **Аутентификация и регистрация**: Вход и регистрация пользователей с проверкой токенов.
- **Управление заявками**: Создание, просмотр, редактирование статуса и приоритета заявок, а также назначение исполнителей.
- **Чат в заявках**: Обсуждение заявок с поддержкой прикрепления файлов и уведомлений в реальном времени.
- **Профиль пользователя**: Обновление личной информации и смена пароля.
- **Статистика**: Визуализация данных по заявкам с помощью круговых диаграмм и гистограмм.
- **Адаптивный дизайн**: Поддержка десктопных и мобильных устройств с использованием Material-UI и кастомных стилей.

## Технологический стек

- **React 18**: Библиотека для создания пользовательского интерфейса.
- **Vite**: Современный инструмент сборки с поддержкой горячей перезагрузки (HMR).
- **Material-UI (MUI)**: Компоненты пользовательского интерфейса и кастомизация темы.
- **Redux Toolkit**: Управление состоянием приложения и асинхронными запросами через RTK Query.
- **React Router**: Навигация между страницами приложения.
- **Socket.IO Client**: Поддержка чата в реальном времени.
- **Chart.js / React-ChartJS-2**: Визуализация данных в виде диаграмм.
- **Framer Motion**: Анимации для улучшения UX.
- **React Hook Form**: Управление формами с валидацией.
- **Axios**: Выполнение HTTP-запросов к серверу.
- **ESLint**: Обеспечение качества кода с использованием правил для React и Hooks.

## Структура проекта

- **`src/`**: Основная директория исходного кода.
  - **`components/`**: Переиспользуемые UI-компоненты (например, `ControlledTextField`, `FileUploader`).
  - **`features/`**: Модули функциональности (аутентификация, профиль, заявки, статистика).
    - **`auth/`**: Логика входа и регистрации.
    - **`profile/`**: Управление профилем пользователя.
    - **`tickets/`**: Управление заявками и чатом.
    - **`stats/`**: Визуализация статистики.
  - **`layouts/`**: Макеты страниц (аутентификация, основной интерфейс, skeleton-загрузка).
  - **`pages/`**: Компоненты страниц (вход, регистрация, список заявок, профиль, статистика).
  - **`store/`**: Конфигурация Redux и срезы состояния.
  - **`utils/`**: Вспомогательные утилиты (Toast, API-обработка).
  - **`hooks/`**: Пользовательские хуки (например, `useSocket`, `useNotifications`).
  - **`constants/`**: Константы (API URL, статусы, приоритеты, сообщения).
- **`index.html`**: Точка входа приложения.
- **`vite.config.js`**: Конфигурация Vite с плагинами и оптимизацией сборки.

## Основные страницы

1. **Вход и регистрация** (`/auth/login`, `/auth/register`):
   - Формы для аутентификации и создания аккаунта с валидацией и уведомлениями.
2. **Список заявок** (`/`):
   - Отображение созданных и назначенных заявок с фильтрацией по статусу, приоритету и поиску.
   - Поддержка уведомлений о новых сообщениях.
3. **Создание заявки** (`/tickets/create-ticket`):
   - Форма для создания новой заявки с выбором исполнителя, приоритета и загрузкой файлов.
4. **Страница заявки** (`/tickets/:id`):
   - Детали заявки, управление статусом и исполнителем, чат с поддержкой файлов.
5. **Профиль** (`/profile`):
   - Обновление личной информации и смена пароля.
6. **Статистика** (`/stats`):
   - Круговая диаграмма статусов и гистограмма приоритетов заявок.

## Установка и запуск

1. **Установите зависимости**:

   ```bash
   npm install
   ```

2. **Запустите приложение в режиме разработки**:

   ```bash
   npm run dev
   ```

3. **Соберите приложение для продакшена**:

   ```bash
   npm run build
   ```

4. **Предварительный просмотр сборки**:

   ```bash
   npm run preview
   ```

5. **Проверка кода с ESLint**:
   ```bash
   npm run lint
   ```

## Конфигурация

- **API URL**: Настраивается в `src/constants/constants.js` (`API_URL`).
- **Тема MUI**: Кастомизация цветов, типографики и компонентов в `src/theme.js`.
- **WebSocket**: Настройка подключения в `src/socket.js` с поддержкой переподключения.

## Оптимизация

- **Vite Bundle Analyzer**: Анализ размера бандла для оптимизации.
- **Manual Chunks**: Разделение кода на чанки (`vendor`, `charts`) для ускорения загрузки.
- **Lazy Loading**: Компоненты `TicketForm` и `TicketChat` загружаются лениво для повышения производительности.
- **React.memo**: Оптимизация рендеринга компонентов (`StatsCharts`, `StatsSummary`, `TicketDetailsAndActions`, `ChatMessage`).

## Особенности

- **Адаптивность**: Интерфейс оптимизирован для мобильных и десктопных устройств с использованием медиа-запросов и динамических макетов.
- **Уведомления**: Реализованы через Toast и WebSocket для мгновенного информирования.
- **Безопасность**: Обработка ошибок авторизации (401) с автоматическим выходом и перенаправлением на страницу входа.
- **Skeleton Loading**: Отображение заглушек во время загрузки данных для улучшения UX.
- **Локализация**: Поддержка русского языка в интерфейсе и сообщениях.

## Требования

- Браузер: Современные версии Chrome, Firefox, Safari, Edge
