# Сервис Заявок

## Описание проекта

**Сервис Заявок** — это веб-приложение для управления заявками, обеспечивающее взаимодействие пользователей через REST API и WebSocket. Приложение состоит из серверной части (Node.js, Express, MongoDB) и клиентской части (React, Vite), предоставляя функциональность для регистрации, аутентификации, создания и управления заявками, общения в реальном времени, управления профилями и категориями, а также просмотра статистики.

### Основные функции

- **Аутентификация и авторизация**: Регистрация, вход, управление ролями и смена пароля с использованием JWT.
- **Управление заявками**: Создание, просмотр, редактирование и удаление заявок с поддержкой загрузки файлов и проверки на вирусы (ClamAV).
- **Чат в реальном времени**: Обмен сообщениями в заявках через WebSocket с уведомлениями.
- **Профили и категории**: CRUD-операции для профилей пользователей и категорий заявок.
- **Статистика**: Визуализация данных по заявкам (статусы, приоритеты) через круговые диаграммы и гистограммы.
- **Адаптивный интерфейс**: Поддержка десктопных и мобильных устройств с использованием Material-UI.
- **Логирование и кэширование**: Логирование с Winston и кэширование с NodeCache для оптимизации.

## Технологический стек

### Серверная часть

- **Node.js**: Среда выполнения (версия >= 18.x).
- **Express**: Фреймворк для REST API.
- **MongoDB / Mongoose**: Хранение данных и управление схемами.
- **Socket.IO**: Чат в реальном времени.
- **JWT (jsonwebtoken)**: Аутентификация и авторизация.
- **Bcryptjs**: Хеширование паролей.
- **Multer**: Обработка загрузки файлов.
- **ClamAV**: Проверка файлов на вирусы (опционально).
- **Winston**: Логирование.
- **NodeCache**: Кэширование данных.
- **Morgan**: Логирование HTTP-запросов.
- **Express-validator**: Валидация входных данных.
- **@hapi/boom**: Обработка ошибок.
- **CORS**: Поддержка кросс-доменных запросов.
- **Dotenv**: Управление переменными окружения.

### Клиентская часть

- **React 18**: Библиотека для пользовательского интерфейса.
- **Vite**: Инструмент сборки с горячей перезагрузкой (HMR).
- **Material-UI (MUI)**: Компоненты UI и кастомизация темы.
- **Redux Toolkit**: Управление состоянием и асинхронные запросы (RTK Query).
- **React Router**: Навигация между страницами.
- **Socket.IO Client**: Подключение к WebSocket.
- **Chart.js / React-ChartJS-2**: Визуализация данных.
- **Framer Motion**: Анимации для улучшения UX.
- **React Hook Form**: Управление формами с валидацией.
- **Axios**: HTTP-запросы к серверу.
- **ESLint**: Обеспечение качества кода.

## Основные возможности

### Клиентская часть

- **Страницы**:

  - Вход и регистрация (`/auth/login`, `/auth/register`): Формы с валидацией.
  - Список заявок (`/`): Фильтрация, поиск, уведомления о новых сообщениях.
  - Создание заявки (`/tickets/create-ticket`): Форма с выбором исполнителя и загрузкой файлов.
  - Страница заявки (`/tickets/:id`): Детали, управление статусом, чат.
  - Профиль (`/profile`): Обновление данных и смена пароля.
  - Статистика (`/stats`): Диаграммы статусов и приоритетов.

- **Особенности**:
  - Адаптивный дизайн с Material-UI.
  - Уведомления через Toast и WebSocket.
  - Ленивая загрузка компонентов (`TicketForm`, `TicketChat`).
  - Skeleton-загрузка для улучшения UX.
  - Локализация на русском языке.

### Серверная часть

- **Эндпоинты**:

  - Аутентификация: Регистрация, вход, управление пользователями и ролями.
  - Заявки: CRUD-операции, пагинация, статистика по периодам.
  - Сообщения: Создание и получение сообщений в заявках.
  - Профили и категории: CRUD-операции.
  - Уведомления: Получение и отметка как прочитанных.

- **WebSocket**:

  - События: `joinTicket`, `resetNotifications`, `notificationsReset`.

- **Безопасность**:
  - JWT для аутентификации.
  - Валидация входных данных (`express-validator`).
  - Проверка файлов на вирусы (ClamAV, опционально).
  - Санитизация имен файлов (`sanitize-filename`).

## Установка и запуск

### Требования

- **Node.js**: >= 18.x
- **MongoDB**: >= 4.4 (для сервера)
- **Docker**: Для контейнеризации
- **Браузер**: Современные версии Chrome, Firefox, Safari, Edge

### Локальная установка (без Docker)

1. **Клонируйте репозиторий**:

   ```bash
   git clone <repository-url>
   cd project
   ```

2. **Установите зависимости**:

   - Для сервера:
     ```bash
     cd server
     npm install
     ```
   - Для клиента:
     ```bash
     cd client
     npm install
     ```

3. **Настройте переменные окружения**:
   Создайте файл `.env` в корне проекта:

   ```plaintext
   # Для сервера
   DB_URI=mongodb://localhost:27017/ticket-service
   JWT_SECRET=your_jwt_secret_here
   PORT=3000

   # Для клиента
   API_URL=http://localhost:3000
   ```

4. **Запустите MongoDB**:
   Убедитесь, что MongoDB запущена локально или в контейнере:

   ```bash
   docker run -d -p 27017:27017 --name mongo mongo:6.0
   ```

5. **Запустите сервер**:

   ```bash
   cd server
   npm run dev
   ```

6. **Запустите клиент**:

   ```bash
   cd client
   npm run dev
   ```

7. **Доступ**:
   - Клиент: `http://localhost:3001`
   - Сервер: `http://localhost:3000`

### Запуск через Docker

1. **Создайте файл `.env`** в корне проекта:

   ```plaintext
   JWT_SECRET=your_jwt_secret_here
   ```

2. **Убедитесь, что структура проекта соответствует описанной выше**.

3. **Запустите приложение**:

   ```bash
   docker-compose up --build
   ```

4. **Доступ**:
   - Клиент: `http://localhost:3001`
   - Сервер: `http://localhost:3000`
   - MongoDB: `localhost:27017` (для локального подключения, если нужно)

### Сборка для продакшена

- **Клиент**:
  ```bash
  cd client
  npm run build
  npm run preview
  ```
- **Сервер**:
  ```bash
  cd server
  node index.js
  ```

## Конфигурация

- **Сервер**:

  - `DB_URI`: URL для подключения к MongoDB (например, `mongodb://mongo:27017/ticket-service` в Docker).
  - `JWT_SECRET`: Секрет для подписи JWT-токенов.
  - `PORT`: Порт сервера (по умолчанию 3000).
  - Логи сохраняются в `server/logs/` (error.log, info.log, combined.log).
  - Файлы загружаются в `server/Uploads/`.

- **Клиент**:
  - `API_URL`: URL сервера (например, `http://server:3000` в Docker или `http://localhost:3000` локально).
  - Тема MUI настраивается в `client/src/theme.js`.
  - WebSocket подключается автоматически к серверу.

## Оптимизация

- **Сервер**:

  - Кэширование списков пользователей и профилей (`NodeCache`, TTL 10 минут).
  - Ограничение размера запросов (1 МБ).
  - Пагинация для списков заявок.
  - Логирование с временными метками (Winston).

- **Клиент**:
  - Ленивая загрузка компонентов (`TicketForm`, `TicketChat`).
  - Разделение кода на чанки (`vendor`, `charts`) через Vite.
  - Оптимизация рендеринга с `React.memo`.
  - Анализ бандла через Vite Bundle Analyzer.

## Безопасность

- **Сервер**:

  - JWT для аутентификации (`authMiddleware.js`).
  - Валидация входных данных (`express-validator`).
  - Проверка файлов на вирусы (ClamAV, опционально).
  - Санитизация имен файлов (`sanitize-filename`).
  - CORS для безопасного взаимодействия с клиентом.

- **Клиент**:
  - Обработка ошибок 401 с перенаправлением на страницу входа.
  - Валидация форм через `react-hook-form`.
